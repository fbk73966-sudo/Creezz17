# Creezz17 Project

Selamat datang di repository resmi **Creezz17**! 
Repository ini merupakan ruang pengembangan dan arsip *changelog* untuk proyek game 3D Android yang sedang dikerjakan secara santai/indie. *(Catatan: **Creezz17** adalah identitas/nama kode proyek—judul resmi game ini masih dalam tahap pengembangan).*

---

## 🎮 Tentang Proyek Ini
Sebuah proyek game aksi 3D untuk perangkat Android yang berfokus pada eksplorasi mekanik dasar karakter dan pertarungan.

### Fitur Utama Saat Ini (v0.0.2 - Pre-release):
* **3D Character & Environment**
* **Dual Camera View:** Mendukung sudut pandang *First-Person* (FPS) dan *Third-Person* (TPS) yang bisa diganti-ganti (*Switch POV*).
* **Kontrol & Pergerakan:** Kontrol analog untuk bergerak, mekanik lompat (*Jump*), dan merunduk (*Crouch*) lengkap dengan animasi.
* **Sistem Pertarungan:** Mekanik memukul (*Punch*) dengan animasi dan musuh berbasis *NPC Enemy*.

---

## 📥 Cara Download & Instalasi
1. Buka tab **[Releases](../../releases)** yang ada di halaman repository ini.
2. Pilih versi terbaru (saat ini bertanda **Pre-release**).
3. *Scroll* ke bagian **Assets** di paling bawah, lalu unduh file **`.apk`** yang tersedia.
4. Instal file `.apk` di perangkat Android kamu *(izinkan instalasi dari sumber tidak dikenal jika diminta)*.

---

## 🛠️ Aturan Modding (Modding Policy)
Proyek ini terbuka bagi siapa saja yang tertarik untuk bereksperimen atau membuat mod!
* **Diperbolehkan:** Membuat, mengembangkan, dan membagikan file mod, *plugin*, atau *mod loader* secara terpisah.
* **Tidak Diperbolehkan:** Meng-upload ulang file `.apk` utama (baik versi asli maupun yang sudah dimodifikasi) di situs atau platform lain. Semua pemain tetap diarahkan untuk mengunduh file game utama langsung dari halaman **Releases** di repository ini.
